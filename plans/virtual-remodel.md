# 가상 리모델링 블루프린트

> 목표: **고객이 자기 집을 LiDAR로 스캔하고, 3D로 띄운 집에 LG 제품을 골라 놓아 보며 색·재질을 바꿔 보는 가상 리모델링.**
> 그다음 채광·와이파이·동선까지 따져서 "실제로 살 집"을 미리 살아 보게 한다.
> 작성 2026-11-19. 상위 계획: [`plan.md`](../plan.md) Phase 8~12. 진행 방식: 단계마다 테스트 먼저(RED → GREEN → REFACTOR).
> 작업 모드: main 직접 반영 (팀 저장소 방식). 단계마다 `uv run pytest` 통과 후 커밋·push.

## 지키는 원칙

- 판정·시뮬레이션 수치는 **코드가 계산**한다. LLM은 설명만 (CLAUDE.md).
- 카탈로그는 LGE.COM 값만. 없는 값은 null → "판정 불가".
- 채광·와이파이·동선은 **근사 모델**이다. 화면에 "참고용 시뮬레이션"이라고 표시하고, 쓰는 가정(모델·상수)을 결과와 함께 보여 준다.
- 모든 상수는 `.env`로 바꿀 수 있게 한다.

## S1. 셀프 스캔을 기본 흐름으로

**할 일**
- 첫 화면을 "내 집 스캔 올리기"로 바꾼다: USDZ 끌어 놓기 + 도면(선택) + UGScan 내보내기 안내 3줄. 올리면 바로 고객 화면(`#/c/:pid`)으로.
- `scanned_by` 기본값 `customer`. 기사 방문·상담 신청은 "방문 스캔 신청" 보조 링크로 내린다.
- 샘플 체험: 실제 스캔 샘플(`ugscan_2026-11-18.usdz`)로 바로 시작하는 버튼.
- `docs/specs/web.md`, 기획 대비 변경점을 `plan.md`에 기록.
**검증**: `tests/integration/test_api_flow.py`에 셀프 스캔 업로드 → 고객 링크 흐름 테스트. Playwright로 첫 화면 업로드 → 고객 화면 진입 확인.
**완료 기준**: 고객이 첫 화면에서 파일 하나 올리고 3D 집을 보기까지 클릭 2번 이내.

## S2. 자유 배치 판정 엔진 (recommender)

**맥락**: 지금 `place_product`는 영역 안에서 가장 좋은 벽을 골라 자동으로 놓는다(`recommender/fit.py` `check_fit` → `placement`). 고객이 **원하는 자리·방향**에 놓고 옮길 수 있어야 한다.
**할 일** (테스트 먼저, `tests/unit/test_pose.py`)
- `check_pose(room, product, pose, others, hidden)` → 판정 + 이유 목록.
  - pose = `{center_xz, yaw_rad, mount: floor|wall}`, 크기는 카탈로그 `product_dims_mm`(없으면 판정 불가).
  - 검사: ① 방 안에 있는지 (벽 다각형 포함) ② 벽 관통 ③ 스캔 가구와 겹침 (숨긴 가구 제외) ④ 다른 배치 제품과 겹침 ⑤ 문 열림 반경 침범 (문 폭 반지름 사분원, 경첩 방향 모르면 양쪽 중 덜 겹치는 쪽) ⑥ 창 아래면 높이가 창턱 이하인지 ⑦ 천장 높이 ⑧ 이격(`clearance_mm`) 확보.
  - 결과 단계는 기존 규칙과 같다: 겹침·관통 → 불가, 여유 < 마진 → 조건부, 값 없음 → 판정 불가.
- 벽 붙이기(snap): 가장 가까운 벽에서 `FIT_SNAP_M`(기본 0.3) 안이면 등을 벽에 붙이고 yaw를 벽 방향으로.
- 배치 데이터 모델: `placements[]`에 `placement_id`, `pose`, `sku`, `color`, `verdict`, `reasons`. 기존 zone 기반 배치는 pose로 변환해 호환.
- `docs/specs/fit-rules.md`에 "자유 배치" 절 추가.
**검증**: 단위 테스트(겹침·관통·문 반경·창턱·snap 각각 1개 이상), 기존 76개 유지.
**완료 기준**: 임의 위치·회전에서 판정이 결정론적으로 나오고 이유가 사람이 읽을 수 있는 한국어 라벨로 나온다.

## S3. 배치 화면 (평면도 · 3D)

**맥락**: 고객 화면은 영역 지정 → 추천 카드 구조. 이제 **제품 고르기 → 놓기 → 옮기기·돌리기**가 중심이다.
**할 일**
- 제품 서랍: 카테고리 탭(냉장고·김치냉장고·식기세척기·쿡탑·정수기 …), 검색, 실제품만 기본(가상 데이터는 배지).
- 평면도: 제품을 끌어다 놓기, 끌어서 이동, 회전 핸들(15° 단위, Shift로 자유), 벽 근처 자동 붙기. 놓는 동안 판정 색(초록·노랑·빨강) 실시간.
- 3D: 배치 제품을 제품 치수 박스 + 선택 색상으로 표시, 클릭 선택 → 평면도와 동기.
- 영역 지정은 "이 영역 안에서 추천" 보조 기능으로 유지.
- API: `POST /api/projects/{pid}/placements`(pose 지정), `PATCH .../placements/{id}`(이동·회전·색), `DELETE`. 이동 중에는 `POST .../pose-check`로 저장 없이 판정만.
**검증**: API 통합 테스트, Playwright로 끌어 놓기 → 판정 배지 → 이동 → 저장 확인. 휴대폰 폭(390px)에서도 조작 가능.
**완료 기준**: 실제 스캔 샘플에서 냉장고를 벽에 붙여 놓고 옮기면 판정이 바뀌는 것을 3D와 평면도 양쪽에서 확인.

## S4. 기존 가구 숨기기 · 재질 바꾸기

**검증**: 숨긴 가구 자리에 제품을 놓으면 겹침이 사라지는 단위·통합 테스트.

## S6. 채광 시뮬레이션

**필요한 데이터**
| 데이터 | 어디서 | 없을 때 |
|---|---|---|
| 창 위치·폭·높이·창턱 | 스캔 (`openings`) ✅ | - |
| **북쪽 방향** | 스캔에 없음 (RoomPlan은 나침반 방향을 저장하지 않음) → 고객이 평면도에서 나침반 돌려 지정, 또는 휴대폰 나침반 값 입력 | 결과를 "방향 미지정"으로 막음 |
| 위도·경도 | 주소 대신 시·도 선택 (기본 서울) | 서울 |
| 날짜·시각 | 화면 슬라이더 (기본: 오늘, 동지·하지 바로가기) | 오늘 |
| 층·앞 건물 가림 | 고객 입력(선택): 앞 건물까지 거리·높이 | 가림 없음으로 가정, 표시 |

**할 일**
- `sim/solar.py`: 태양 고도·방위 (NOAA 근사식, 순수 Python). 테스트: 서울 하지·동지 정오 고도 기준값과 ±0.5° 이내.
- 창을 통과한 직사광 바닥 투영 다각형 → 시각별 일사 영역, 하루 직사 시간 히트맵(그리드 0.25 m).
- 결과: 영역·제품 위치별 "하루 직사광 n시간". 예: 김치냉장고·정수기 자리에 직사광이 길면 주의 표시.
**완료 기준**: 평면도에 시간 슬라이더를 움직이면 햇빛 자리가 움직이고, 모델 가정이 같이 표시된다.

## S7. 와이파이 커버리지

**필요한 데이터**
| 데이터 | 어디서 | 없을 때 |
|---|---|---|
| 벽 위치 | 스캔 ✅ | - |
| **공유기 위치** | 고객이 평면도에 놓음 (현재 위치), 또는 "추천 자리 찾기" | 추천 모드만 |
| 벽 재질 감쇠 | 기본값(콘크리트·석고보드 dB)을 `.env`, 벽별로 고객이 바꿀 수 있음 | 기본값, 표시 |
| 대역 | 2.4 / 5 GHz 선택 | 5 GHz |
| 문·가구 | 스캔 ✅ (문은 열림 가정, 가구 감쇠는 무시하고 명시) | - |

**할 일**
- `sim/wifi.py`: 다중 벽 경로손실 모델 (자유공간 손실 + 통과 벽 수 × 벽 감쇠). 테스트: 벽 0·1·2장 통과 시 값이 식과 일치, 대칭성.
- 신호 세기 히트맵(dBm) + 등급(좋음/보통/약함). 공유기 후보 자리 자동 탐색(최약 지점 최대화).
- 냉장고 등 금속 대형 가전 배치 시 뒤쪽 그늘(감쇠)도 반영 → 배치와 연결.
**완료 기준**: 공유기를 옮기면 히트맵이 바뀌고, "안방 약함" 같은 영역별 요약이 나온다.

## S8. 이동 동선

**필요한 데이터**
| 데이터 | 어디서 | 없을 때 |
|---|---|---|
| 벽·문·가구 | 스캔 ✅ | - |
| 배치 제품·숨긴 가구 | S2~S4 ✅ | - |
| 문·가전 문 열림 | 문 폭(스캔), 가전 `door_swing_mm`(카탈로그, 없으면 null) | 가전 문 열림 검사 판정 불가 |
| 최소 통로 폭 | `.env` `FLOW_MIN_WIDTH_M` (기본 0.9) | 기본값 |
| 주요 지점 | 현관(가장 넓은 문 자동 추정, 고객이 바꿈), 제품 앞, 고객이 찍은 지점 | 현관만 |

**할 일**
- `sim/flow.py`: 점유 격자(0.05 m) → 사람 반폭만큼 팽창 → A* 최단 경로. 테스트: 막힌 통로 → 경로 없음, 폭 0.85 m 통로 → "좁음".
- 표시: 현관 → 각 제품 경로, 좁은 구간 빨간색, 가전 문 열림 범위가 통로를 막는지.
- 주방 작업 삼각형(냉장고·싱크·쿡탑) 길이 합 표시 (싱크는 스캔에 없으면 고객이 지정).
**완료 기준**: 냉장고를 통로 쪽으로 옮기면 "통로 0.7 m로 좁아짐" 경고가 즉시 뜬다.
