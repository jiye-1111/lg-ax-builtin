# 2026 마감재·벽지 트렌드 조사

조사일 2026-11-20. 실제로 파는 벽지·바닥재만 앱에 넣으려고 제조사 발표와 기사로 확인했다.
여기서 고른 16종이 `data/finishes/finishes.json`에 들어 있다.

## 한 줄 정리
**밝고 따뜻한 화이트 바탕 + 손맛 나는 회벽 질감 + 넓은 오크 마루, 그리고 바닥에서 빠르게 늘어나는 스톤(대리석) 패턴.**
포인트 색은 흙빛 브라운·카라멜·테라코타, 더스티 블루, 아티초크 그린.

## 앱에 넣을 때 지킨 것
- 제품명·라인·특징·규격은 출처에 적힌 그대로. 기사에 패턴 이름이 없으면 "회벽 디자인"처럼 종류로만 적었다.
- 기사에 색 번호가 없어서 톤 색은 **화면용 근사색**(`tone_basis: approx`)이다. 앱 카드에도 그렇게 적었다. 공식 색값이 공개된 Cloud Dancer만 `official`.
- 벽지 사진은 가져다 쓰지 않았다. 질감(회벽·직물·스톤·우드·도장)은 웹에서 직접 그린다 (`apps/web/js/finishes.js`).

## 더 할 것
- 제조사 샘플북 품번별 색(예: 클레이어 14컬러 품번)을 확인하면 톤을 공식 값으로 바꾼다.
- 개나리벽지·디앤디 등 다른 제조사 2026 신제품도 확인되면 추가.
