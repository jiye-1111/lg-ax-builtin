# 가구 모양과 색

가구 탭의 가구·장·문·창은 제품 정보 없이 모양과 색만 있다. 2026-11-25에 모양을 전부 다시 만들고, 색을 부위별로 바꿀 수 있게 했다.

색 값(hex)은 화면에서 비슷하게 보이도록 고른 근사색이다. 제조사가 공개한 색 값이 아니다. 브랜드 이름은 화면에 쓰지 않는다.

## 가구별 모양

- 소파: 낮고 깊은 몸통, 두툼한 방석과 등쿠션, 포인트 쿠션 둘, 낮은 검정 발
- 의자: 가는 원목 다리에 천 방석과 굽은 천 등받이
- 식탁·책상: 귀를 굴린 얇은 상판. 식탁은 가늘어지는 원목 다리, 책상은 가는 철제 다리
- 테이블(소파 앞): 귀를 크게 굴린 두툼한 상판에 굵은 원기둥 다리 둘
- 침대: 세로 골이 진 천 헤드, 천을 씌운 낮은 틀
- 서랍장·하부장·싱크대·아일랜드·키큰장·장롱·수납장: 손잡이 없는 무광 문, 손을 넣는 어두운 홈, 들인 걸레받이. 수납장은 가운데에 뚫린 나무 칸
- 거실장: 바닥에서 뜬 낮은 몸통에 템바보드 문
- 문·창문·베란다 유리문: 아래 '문과 창' 참고 (2026-11-26에 다시 만듦)

## 문과 창

2026-11-26에 실제 창호·도어 자료를 보고 다시 만들었다. 스캔이나 도면에서 읽은 문·창도 같은 모델을 그 자리 크기에 맞춰 단다 (`room3d.js` `dressRoom`). 전에는 상자 몇 개로 그렸다.

| 본 자료 | 가져온 것 |
|---|---|
| [KCC 발코니창 규격표](https://www.kccworld.co.kr/materials/window/balconi.do) | 이중창은 창틀이 창짝을 감싸고, 안쪽 미서기 한 벌과 바깥 미서기 한 벌이 따로 달린다. 아래 홈에 알루미늄 레일 |
| [LX Z:IN 뷰프레임 기사 (머니투데이)](https://www.mt.co.kr/future/2024/06/04/2024052915453395874), [한국경제](https://www.hankyung.com/article/2026031889381) | 곡선 없는 곧은 틀, 눈에 덜 띄는 철물 |
| [LX 수퍼세이브 기사 (아시아경제)](https://view.asiae.co.kr/article/2023092110130921056) | 창짝 손잡이, 안쪽 틀 색(흰색·나무 무늬) |
| [오늘의집 새시 교체 글](https://ohou.se/advices/2192) | 두 짝은 1:1, 넓은 창은 여러 짝으로 나눈다 |
| [한샘 ABS 도어](https://store.hanssem.com/goods/1064647) | 문짝 두께 36 mm, 문틀·경첩·손잡이가 한 벌, 문턱 없음 |

- 창문(`window`): 홈이 두 줄인 창틀에 안 창 두 짝, 바깥 창 두 짝. 창짝은 가운데에서 앞뒤로 겹치고, 겹치는 테에 반달 잠금쇠가 달린다. 테 안쪽은 유리 누름대만큼 한 단 얇다.
- 베란다 유리문(`glassdoor`): 같은 구조에 아래 창틀이 낮고 창짝 아래 테가 높다. 창틀 쪽 테에 긴 손잡이.
- 폭 2.4 m가 넘는 창과 3.2 m가 넘는 유리문은 네 짝짜리(`window4`, `glassdoor4`)로 그린다. 가운데 두 짝이 맞닿고 양옆 두 짝은 뒤 레일에 선다.
- 문(`door`): 문짝이 닿는 턱이 있는 문틀, 민자 문짝, 경첩 셋, 둥근 받침 레버 손잡이와 잠금 받침.
- 치수는 위 자료와 흔한 제품을 보고 정한 근사값이다. 특정 제품의 도면이 아니다.
- 유리는 어두운 청록에 옅게(7%) 그린다. 밝은 색으로 두면 여러 장이 겹쳐 뿌옇게 보이고, 매끈하게 두면 조명이 흰 점으로 맺힌다.
- 창밖은 그림 한 장을 모든 창이 같이 쓴다. 눈높이(1.5 m)에 지평선이 오게 높이를 맞춘다: 큰 창이든 작은 창이든 같은 풍경의 다른 부분이 보인다.
- 스캔한 문·창은 재질별로 한 덩이로 합쳐 그린다 (창 하나에 서너 번). 느린 PC에서도 가볍다.
- 문 자리도 벽을 뚫는다. 걸레받이는 문과 유리문 자리에서 끊긴다.

## 색을 바꾸는 부위

`apps/web/js/furncolors.js`의 `PARTS`가 기준이다. 맨 앞 부위가 대표 색(`hex`)이고, 나머지는 `part_colors`에 부위 이름으로 저장한다. 장 상판만 `top_hex`에 둔다 (끼워 넣은 가전 위 상판 덮개가 같은 색을 써야 해서).

| 가구 | 부위 |
|---|---|
| 소파 | 패브릭, 쿠션, 다리 |
| 의자 | 방석, 등받이, 다리 |
| 침대 | 헤드, 프레임, 이불, 담요 |
| 식탁·테이블·책상 | 상판, 다리 |
| 서랍장 | 서랍, 상판, 다리 |
| 거실장 | 몸통, 문 |
| 하부장·아일랜드 | 문, 상판 |
| 싱크대 | 문, 상판, 수전 |
| 수납장 | 문, 안쪽 칸 |
| 문 | 문짝, 문틀, 손잡이 |
| 창문·베란다 유리문 | 창틀, 손잡이 |

3D에서 색을 고르는 중에 가구의 그 부위(의자 등받이, 침대 헤드 등)를 누르면 그 부위로 바로 넘어간다.

## 무늬

모델에는 그림 파일이 없다. 웹이 작은 그림 두 장(나뭇결 512px, 천 짜임 128px)을 그려서 모든 가구가 같이 쓴다. 재질 `extras.tex`가 `wood`면 나뭇결, `fabric`이면 천 짜임이다. 나무 색을 고르면 그 부위에 나뭇결이 입혀지고, 무광 색을 고르면 민무늬가 된다.

## 다시 만들기

```bash
python services/blender-worker/worker/bpy_scripts/build_furniture.py --out apps/web/models/furniture
python services/blender-worker/worker/bpy_scripts/render_decor_thumbs.py --models apps/web/models/furniture --out apps/web/img/decor
node tests/e2e/part_colours.js    # 서버를 켠 채로
```

Blender 실사 장면(`build_scene.py`)은 아직 대표 색과 상판 색만 입힌다. 다리·쿠션 같은 나머지 부위 색은 웹 3D에만 보인다.
