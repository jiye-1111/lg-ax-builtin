# 벽면 맞춤가구 (주방·거실)

벽 하나를 골라 하부 줄·상부 줄로 장을 늘어놓고, 하나의 빌트인 가구처럼 마감하는 기능. 장 하나하나는 그대로 맞춤장(`docs/specs/builtin-kitchen.md`)이다.

## 데이터

- 세트: `scene_state.cab_runs = [{run_id, wall_id, room, start_mm: {base, wall}, rows: {base: [{id, gap_mm}], wall: [...]}}]`. 순서·틈·시작 위치만 적는다.
- 장: 맞춤장 배치(`decor:cab_<종류>`)에 `cab.run = {id, tier, idx}`. 외경·부재·마감·유리·프리셋(`cab.preset`)·손으로 바꾼 치수(`cab.dims_by = "user"`)는 장에 있다.
- 장 안 가전: `in_cab`. `cab_made: false`면 원래 놓여 있던 가전을 연결한 것이라 장을 지워도 가전은 남는다. 장과 같이 만든 가전(`cab_made: true`, 예전 데이터는 값이 없음)은 장과 같이 지운다.
- 프리셋: `data/catalog/cabinet_presets.json`. 치수는 몸체 기준이고 다리(걸레받이)·상판을 더해 외경을 만든다 (하부장 800 + 80 + 30 = 910). `source`로 출처를 나눈다.
  - `ikea_metod`, `ikea_besta`: 요청서에 적힌 IKEA 공개 치수를 시작값으로 썼다. 이 작업에서 IKEA 페이지를 다시 열어 보지 못해 `checked_at`은 비워 뒀다.
  - `housetwin`: 시안용 시작값. 아일랜드·TV월·코너·사이드보드·벤치·거실 상부장·좁은 장·홈카페장·가전 매입부. 제작·시공 규격이 아니다.
- 시작 세트(`starters`): 빈 벽 / 주방 벽면 / 거실 TV월 / 수납 벽면. 고른 뒤에는 장마다 따로 고친다.

## 배치 계산 (`recommender/runs.py`)

- 정면도 좌표 s(mm): 방 안에서 그 벽을 바라봤을 때 왼쪽 끝이 0. 원점은 벽 시작점이나 끝점 중 왼쪽 것.
- 줄마다 `start_mm`부터 `[gap_mm + 장 폭]`을 차례로 쌓는다. 같은 줄 안에서는 겹칠 수 없다.
- 세계 자리: 벽 면(두께 절반)에서 깊이 절반만큼 앞. 정면은 방 안쪽. 상부 줄과 벽걸이 장은 `base_mm` 높이에 건다.
- 사용 폭·남은 폭은 높이 구간마다 따로: 하부 = 하부 줄, 상부 = 상부 줄 + 하부 줄의 키큰장.
- 알리는 것 (장 크기는 절대 줄이지 않는다):
  - 벽 끝을 넘음(`past_wall`), 창문을 가림·문을 막음(`blocks_window`/`blocks_door`/`blocks_opening`): 가로·세로가 모두 겹칠 때만
  - 상부 장이 아래 장과 겹침(`overlap`)
  - 이웃 장 앞선·상판 높이가 다름(`front_line`/`counter_line`, 안내)
  - 벽과 100 mm 안으로 뜸 → 틈막이판, 옆면이 드러남 → 측면 마감판 (안내만, 자동으로 붙이지 않음)
  - 창가 벤치: 창틀까지 남는 높이와 창이 안쪽으로 열리면 현장 확인
  - 코너장은 꺾이는 쪽이 줄 끝에 있어야 함
- 세트 밖 물건(벽·가구·스캔 물건)과 겹침은 평소 배치 판정(`_rejudge_all`)이 낸 까닭을 그대로 붙인다.
- '상판선 맞추기'(`align`): 하부 장 상판 높이를 가장 많이 쓴 높이(같으면 왼쪽)에 맞춘다. 몸체는 그대로, 다리 높이만 바꾼다. 가전 매입부는 가전 공간이 바뀌니 그대로 두고 알린다. 누를 때만 한다.

## API

| 요청 | 하는 일 |
|---|---|
| `GET /api/cabinet/presets` | 프리셋·시작 세트·출처 |
| `POST /api/projects/{pid}/runs/preview` | 사본에 적용해 결과와 사본 장면을 돌려준다. 저장하지 않는다 |
| `POST /api/projects/{pid}/runs` | 확정. 같은 `run_id`면 그 세트를 고친다 (없어진 장은 지운다) |
| `GET /api/projects/{pid}/runs/{rid}` | 저장된 세트의 결과 |
| `DELETE /api/projects/{pid}/runs/{rid}` | 세트와 장을 지운다 (연결만 한 가전은 남김) |

모듈: `{id?, preset? | kind?, gap_mm, outer_mm?, parts?, finish?, glass?, base_mm?, mode?, measured_mm?, dims_by?, app?}`.
`app: {id}` = 이미 놓은 가전 연결, `{sku}` = 그 모델을 새로 넣기, `null` = 빼기. 가전 매입부에 공식 기준이 있는 모델을 고르고 치수를 따로 넣지 않았으면 그 모델 권장 안쪽 치수로 장을 맞춘다. 기준이 없으면 장 크기는 그대로고 판정은 `확인 필요`.

결과는 셋으로 나눈다:
- `fit`: 가전이 들어가는지 (장 판정 `cab_check`. 가전이 없으면 "설치 기준 확인 필요")
- 문·서랍 열림: 화면이 3D 근사로 본다 (`kitchen.js doorReport`, 아일랜드는 `islandPassage`)
- `utilities`: 전기·급배수·방열·배기. 스캔·도면으로는 알 수 없어 `site`(현장 확인)로만 낸다. 싱크 급배수를 확인된 것처럼 보이지 않는다. TV월은 배선 통로·통풍 여유를 따로.
- 치수 출처: 벽 길이 스캔/도면/실측/한 벽 실측 보정, 장 크기 프리셋/입력값/실측. 장이 모두 프리셋이고 벽이 스캔이면 `simulation: true`.

## 세트와 장 하나 고치기

- 패널에서 장 하나를 고치거나 지우면 세트를 다시 늘어놓는다(`_runs_sync`). 폭을 넓히면 오른쪽 장이 밀린다.
- 3D에서 세트 장을 끌어 옮기면 세트에서 빠진다(그 자리에 남는다).
- 벽이 없어진 집(다시 스캔)이면 세트만 풀고 장은 그 자리에 둔다.

## 화면 (`apps/web/js/wallrun.js`)

- 들어가는 곳: 가구·주방·전체 탭 맨 위 `벽면 맞춤가구 만들기`, 빌트인 가전 상세의 `맞춤장 만들기`, 세트 장을 골랐을 때 `벽면 세트 편집`.
- 냉장고 상세 `맞춤장 만들기`: 그 냉장고가 놓여 있으면 가장 가까운 벽에서 그 자리를 감싸는 냉장고장을 연결(`app.id`)해 미리 보여 준다. 안 놓였으면 벽을 고르게 하고 장과 그 모델을 같이 미리 본다.
- 순서: 벽 고르기(3D에서 벽 누르기 또는 칩) → 시작 세트 → 정면도 편집. 고칠 때마다 미리보기를 받아 3D에 그린다. 그동안 2초마다 다시 읽기는 멈춘다.
- 정면도: 창·문, 장(도어 색), 가전 칸, 빈 구간. 누르면 고르고 옆으로 끌면 순서가 바뀐다.
- 고른 장: ‹ › 옮기기, 앞에 넣기, 복제, 교체, 삭제, 폭·몸체 높이 칩과 직접 입력, 깊이, 왼쪽 틈, 바닥에서 밑면, 문짝 유형, 여는 쪽, 유리, 도어·몸통 색, 세트 전체에 같은 색, 넣을 가전(놓인 가전 연결 / 공식 기준 있는 모델 / 없는 모델).
- 취소 = 원래 장면으로 그리기만 한다 (서버에는 아무것도 안 보냈다). 배치 확정만 저장한다.

## 3D 부재 (`apps/web/js/cabinet.js layoutMore`)

- 하부장 계열(하부장·인덕션장·코너장)은 상판·다리, 키큰장·낮은장은 천판, 상부장 계열은 다리 없이 건다.
- 문짝: 여닫이(경첩 반대쪽 손잡이), 서랍, 오픈(문 없음), 인출(한 판, 위 손잡이), 플랩(한 판, 아래 손잡이).
- 홈카페장: 가운데 열린 칸 + 위·아래 수납. 오븐장: 가운데 가전 칸(뒷판 없음), 아래 서랍.
- 코너장: 이 벽(A) 몸통은 꺾인 쪽(B) 몸통 앞에서 끝난다. 상판도 둘로 나눠 겹치지 않는다. 문은 A 또는 B 쪽.
- 수납형 아일랜드: 수납 방향(앞·뒤·양쪽), 반대쪽 상판 돌출, 반도형이면 벽 쪽 마감판.
- TV월: 가운데 TV 칸은 비우고 좌우 키큰 수납·아래 미디어장·위 수납장, 배선 통로는 어두운 띠.
- 인덕션장: 공식 타공 치수(`cutout_w`·`cutout_d`)를 넣었을 때만 상판에 구멍.

## 아직 안 된 것

- 코너장은 한 벽 세트 안의 모듈이다. 옆 벽 세트와 자동으로 이어 붙이지 않는다(옆 벽 세트의 시작 위치를 꺾인 쪽 길이만큼 띄워야 한다).
- 문 열림 3D 근사는 장 안 가전 문과 아일랜드 서랍까지. 일반 장 문짝끼리 부딪치는지는 아직 안 본다.
- TV월 TV 칸은 TV 모델을 고르면 그 TV가 칸에 들어가지만, TV 모델별 공식 매입 기준은 없어 `확인 필요`로 나온다.
