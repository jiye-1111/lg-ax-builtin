# 왼쪽 필터와 화면 배치 (2026-11-21)

필터 목업과 UI 분석(잘된 점·개선 방향)을 받아 왼쪽 제품 탐색을 다시 짰다.

## 화면
- 순서: 카테고리(전체·LG 가전·가구·수납·소품 한 줄 세그먼트) → 설치 방식(빌트인·일반 둘 중 하나, 개수 표시) → 품목(용도 칩 + 품목 칩, 두 줄 넘으면 "품목 더 보기") → 가격 범위(최소·최대 금액 입력 + 손잡이 두 개) → 상세 필터(크기, 품목을 고르면 색상·용량·도어 등).
- 조건은 고르는 대로 바로 반영된다. "적용하기 (n)"는 필터 칸을 접고 목록을 보여 주는 버튼이고, 고른 조건은 목록 위 칩으로 남아 ×로 하나씩 뺀다. "필터 초기화"는 전부 지운다.
- 제품 카드: 사진 · 이름 · 모델명 · 가격, 아래 줄에 색상 동그라미(5개까지, 나머지는 +n)와 "배치하기". 가격 범위를 고르면 카드의 대표 모델도 그 범위 안의 것으로 바뀐다.
- 큰 화면은 3D 약 79% · 제품 탐색 약 21%(`clamp(288px, 21vw, 348px)`). 패널 오른쪽 가장자리 손잡이(`#libFold`)로 접으면 3D가 가득 찬다. 접은 상태는 기억한다.
- 3D 아래 채광·와이파이·동선 정보 칸은 "정보 접기"(`#simFold`)로 접는다.
- 1100px 이하는 전과 같이 3D 꽉 + 아래 서랍. 서랍을 열어야 필터가 보인다.

## 코드
- `apps/web/js/filters.js`: 적용된 조건 칩(`appliedFilters`), 하나 빼기(`clearFilter`), 상세 필터 개수, 금액 읽기·쓰기. 순수 함수라 `node --test tests/web/`로 본다.
- 가격 눈금은 `options.js priceScale`(실제 판매가, 초고가는 맨 오른쪽 "이상").
- 화면 점검: `node tests/e2e/filter_panel.js` (서버를 켠 뒤). 헤드리스는 소프트웨어 렌더라 느리다.

## 남은 것
- 에너지 소비효율 필터: 카탈로그에 등급 값이 없다. LGE.COM에서 등급을 확인해 넣은 뒤에 추가.
- `tests/e2e/demo_flow.js`는 LG 가전 탭을 누르지 않아 첫 단계에서 멈춘다(탭이 생긴 뒤로 그대로). 손봐야 한다.
