# 리모델링 화면 다시 배치 (2026-11-20)

지예가 보낸 정정 목업과 "복잡하면 안 된다, 너무 단순해도 안 된다"는 피드백대로 정리했다.
Figma는 Starter 플랜 MCP 월 한도에 걸려 그리지 못했고, 바로 코드로 옮겼다.

## 화면
- 위: 3단계 진행(공간 확인 → 제품 고르기 → 설치 확인, `guide.js stepState`). 로그인·저장·다른 집 스캔은 "저장 · 내 집" 메뉴 하나(`#homeMenu`). 리모델링 화면에서는 맨 위 메뉴 링크를 숨긴다.
- 왼쪽: 검색, 용도·종류, "이 집에 들어가는 제품" 3개(`#sugg`, `/suggest`), 접힌 "상세 필터"(옵션 단계 + 폭·높이 + 가격대, 필터 초기화), 정렬(추천순·낮은 가격순·작은 크기순).
- 3D 위 도구 줄: 처음과 비교, 살아 보기, 벽지·바닥, 가구 치우기, 도면·실측 / 되돌리기·다시 실행·전체 화면·안내 다시 보기·조작키.
- 살아 보기: 버튼을 누르면 줄이 열리고 둘러보기·채광·와이파이·동선을 고른다. 끝내기로 닫는다. 평소에는 켜고 끄는 토글이 안 보인다.
- 3D 안: 고른 제품 판정 한 줄(`#fitBadge`), 아래 이동·회전·자동 정렬·삭제(`#actBar`). 제품을 고른 채로는 "알맞은 자리에 놓기". 3D/평면/나란히 버튼은 없애고 왼쪽 아래 작은 평면도의 "평면도 보기"로 바꾼다.
- 오른쪽: 탭 없음. 고른 제품 카드(사진·이름·용량·색·치수·판매가, 설치 가능 배너, 놓을 공간·문 여는 공간·통행 공간·채광·와이파이), 안 골랐으면 놓은 제품 목록. 아래 "구매 및 설치 신청".
- 영역 그리기와 "추천" 탭은 뺐다. 추천은 하우니 대화로(지예 결정). 하우니가 제품을 찾아 주면 대화창에 카드와 "넣어 보기"가 나온다.
- 첫 안내(`js/tour.js`): 주변을 어둡게 하고 하우니가 "집 스캔이 끝났어요" → 메뉴를 하나씩 → "직접 체험해 볼까요?"(누르면 알맞은 자리에 하나 놓아 줌). 한 번 보면 localStorage에 적어 다시 안 뜬다.

## 서버
- `POST /api/projects/{pid}/placements/{id}/auto-align`: 가까운 벽에 붙이고, 안 되면 `find_spot`으로 가장 잘 들어가는 자리로.
- `POST /api/projects/{pid}/suggest {skus ≤60, limit}`: 후보 가운데 벽을 따라 실제로 들어가는 것만 적합 순.
- `GET /api/projects/{pid}/life-check?date=`: 놓은 제품마다 하루 직사광 시간(냉장고류는 직사광 주의)과 와이파이 세기. 북쪽을 안 정했으면 큰 창 기준으로 추정해서 계산하고 저장은 안 한다. 공유기가 없으면 "정하기" 버튼으로 살아 보기 와이파이로 보낸다.

## 남은 것
- 휴대폰 화면은 깨지지 않을 정도로만 맞췄다. 한 번 더 다듬기.
- 채광 "충분해요" 같은 좋고 나쁨 판단은 제품마다 기준이 달라서 지금은 시간만 알려 준다(냉장고류만 직사광 주의).
