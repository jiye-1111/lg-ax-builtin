# 채광 작업 인계 메모 (2026-11-20)

브랜치: `claude/project-thread-nwdpjq` (main에서 갈라짐, PR은 아직 없음)

## 끝난 것
- **물체에도 햇빛** (`apps/web/js/viewer.js`): 가구·제품이 주변 반사광(envMap) 때문에 어디서나 똑같이 밝아서 볕이 닿은 면이 구분되지 않았다. 실제 해 모드에서는 재질별 `envMapIntensity`를 `0.08 + 0.3 × sky`배로 낮춘다(`applyEnv`, 원래 값은 `material.userData.baseEnv`). 하늘빛(hemi)은 조금 올렸다. `sunInfo().env`로 확인할 수 있다.
- **방향 계산** (`services/sim/sim/orientation.py`, 테스트 `tests/unit/test_orientation.py`)
  - `window_facings(room, north_deg)`: 창이 있는 벽마다 남향·북향 등
  - `estimate_north(room, axis_deg=None)`: 가장 큰 창이 남쪽을 본다고 가정. 건물 변 방향을 알면 그 변 중 남쪽에 가장 가까운 면에 맞춘다
  - `footprint_axis_deg(ring)`: 건물 외곽선 → 주된 변 방향
- **주소 → 위도·경도** (`services/sim/sim/geocode.py`): Nominatim(`polygon_geojson=1`로 건물 외곽선까지). `.env`의 `GEOCODER_URL`, `GEOCODER_USER_AGENT`, `GEOCODER_TIMEOUT_S`로 바꿀 수 있다. 응답 모양은 실제 호출로 확인했다(서울시청 주소 → 좌표 + Polygon).

- **연결**: `Service.set_site(address=, auto_north=)`, `daylight()` 응답의 `facings`, API `SiteIn`. 웹 채광 카드에 주소 입력과 "남향 집이에요" 표시. 북쪽을 안 정했으면 자동 추정한다.
