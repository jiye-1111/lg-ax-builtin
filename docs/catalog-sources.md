## 2026-11-20 추가: 가격

- `price_krw`: LGE.COM 제품 페이지에 보이는 판매가(원). 페이지 데이터의 `obsSellingPrice` 값이고, 검색엔진용 정보(JSON-LD `price`)와 같은 값이다. 쿠폰·카드·구독 할인은 넣지 않았다. 확인한 날은 `price_checked_at`.
