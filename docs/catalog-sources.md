- 상세 창의 "재질" 줄과 3D·실사의 문짝 빛남은 LGE.COM 스펙 표의 "도어스타일/재질" 값을 쓴다 (`options.door_material`, 없으면 `cmf_options[0].material`). 2026-11-25에 제품 페이지 1,175개를 다시 훑어 보니 이 항목은 냉장고·김치냉장고·냉동고·와인셀러에만 있었다. 같은 날 들어온 묶음 65개까지 더해 지금 재질이 적힌 건 270개다. 다른 종류는 재질이 적혀 있지 않아 줄을 띄우지 않고 모델도 그대로 둔다.
- 빛남 규칙은 `apps/web/js/surface.js`와 `services/core/core/surface.py` 두 곳에 같은 값으로 있다. 스테인리스·스톤, 메탈(퓨어·실버·그라파이트처럼 금속 결이 보이는 색 / 흰색·베이지처럼 칠한 강판), 글라스·미러, 미스트 글라스로 나눈다. 메탈을 색 이름으로 둘로 나눈 건 우리가 정한 표현 규칙이고 LGE.COM에 적힌 값은 아니다.

## 2026-11-26 추가: 실사용 제품 사진

- `data/catalog/photo_refs.json`은 지금 내놓는 412개 모델의 LGE.COM 제품 페이지 대표 사진(og:image) 주소다. 2026-11-26에 페이지를 하나씩 열어 읽었다. 대부분 `gallery/medium01.jpg`(정면 누끼)이고, 스타일러·일부 와인셀러처럼 대표 사진이 다른 컷인 것도 그대로 뒀다.
